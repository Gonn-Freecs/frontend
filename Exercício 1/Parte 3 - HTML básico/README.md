<"!DOCTYPE html>: Declara o tipo de documento, avisando ao navegador que é um documento HTML 5.

<"html>: O elemento raiz de uma página HTML. Todo o conteúdo da página fica dentro desta tag.

<"html lang>: Especifica o idioma do conteúdo textual dentro de um elemento HTML.

<"title>: Define o título da página que aparece na aba do navegador ou na barra de título da janela.

<"head>: Contém metadados sobre o documento, como título da página  links para folhas de estilo CSS, scripts JavaScript e outras informações que não são exibidas diretamente na página.

<"body>: Contém todo o conteúdo visível da página web, como textos, imagens, links etc.

<"h1>, <"h2>, <"h3>, <"h4>: Tags de cabeçalho, onde <"h1> é o mais importante e <"h6> o menos importante.

<"p>: Define um parágrafo do texto.

<"ul>: Define uma lista não ordenada (com marcadores).

<"li>: Define um item de lista dentro de <"ul> ou <"ol>.

<"ol>: Define uma lista ordenada (com números ou letras).
