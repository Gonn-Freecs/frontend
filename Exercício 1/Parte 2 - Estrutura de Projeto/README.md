O indel.html é a entrada principal para o site é ele que contem o código HTML que estrutura a página. 

A pasta CSS serve para guardar o style.css esse que guarda os estilos visuais e regras de formatação do site.

A pasta img serve como repositório para todas as imagens que sera usáda no projeto.

A pasta js serve para a lógica interativa e o script.js é para armazenar e organizar os códigos que nos entragara dinâmica e interatividade para o site.
