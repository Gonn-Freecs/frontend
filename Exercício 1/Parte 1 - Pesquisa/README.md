O que é FrontEnd: FrontEnd é a parte da programação aonde que é trabalhada a área visual de sites e aplicações, montando a área em que os usuários podem interagir.

Cliente X Servidor: é um modelo de arquitetura de rede amplamente utilizado em ambientes de TI em que os computadores são dividos em dois grupos, servidores que fornecem serviços ou recursos, e clientes, que solicitam estes serviços e recursos, recebendo-os como respostas. Comunicação dos dois sendo feitas por prótocolos TCP/IP, geralmente realziada pela internet ou por uma rede privada.

O papel do HTML, CSS e JavaScript: O papel do HTML é para estruturar o conteúdo do site, aonde todas as coisas iram ficar e como devem ficar, o CSS serve para a customização do site, é com ele que você ira personalizar as cores, fontes, estilos etc, deixando ele mais atraente e chamativo e agora JavaScript tem como papel deixar o site mais dinâmico e interativo como por exemplo animações na entrada do site ou de botões.

O W3C (World Wide Web Consortium) é uma organização internacional de padronização de redes, responsáveis por criar normas técnicas como HTML, CSS e JS(JavaScript). Seu objetivo é garantir a interoperabilidade e o acesso universal, assegurando que a web evolua de forma aberta, segura e consistente para todos os dispositivos.
