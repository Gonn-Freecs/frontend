O objetivo foi ironizar com a ideia principal, que envolvia lápis e objetos de escritura.

A estrutura de pastas é bem simples tendo assets, css e js. O assets tem imagens de background e icon, o css tem o styles.css mantendo cores, temas, fontes, alinhamentos etc já o js obtem o script de fecha a barra lateral, fechar menus depois do scroll da página e outros.

Para abrir o projeto você precisa ir no github entrar em frontend, exercicío 1, Parte 5 - Projeto final, startbootstrap-stylish-portfolio-gh-pages e index.html
